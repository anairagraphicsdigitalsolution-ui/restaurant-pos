Anaira Restaurant POS - Electron

1. Edit electron/config.json and set appUrl to your deployed Cloud/Vercel URL.
2. Run: npm install
3. Run: npm run electron:build
4. Installer: installer/output/Anaira-Restaurant-POS-Setup-1.0.0.exe

This Electron shell keeps Supabase/server secrets on the Cloud deployment; it does not package a local Supabase server.
