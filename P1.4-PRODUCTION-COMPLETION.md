# P1.4 Production Completion

Production is implemented on top of the existing recipe/inventory/COGS stack.

## Flow
Recipe → Production Plan → Prep Stage → Batch → Raw Material Consumption → Production Output → Yield → Waste → Finished Goods → History

## Production controls
- Production planning UI
- Batch start with idempotency
- FIFO raw-material deduction through P1.3 costing engine
- Finished-goods inventory increment
- Batch total/unit costing
- Planned vs actual yield variance
- Yield percentage
- Waste quantity and waste cost
- Production event/history ledger
- Duplicate completion protection
- Restaurant isolation/RLS
