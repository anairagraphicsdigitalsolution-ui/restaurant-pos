# P1.8 Enterprise HQ — Outlet Provisioning & Shared Anaira Application

## Implemented
- Enterprise HQ -> Outlets now has Create Outlet and Connect Existing.
- New outlet provisioning creates:
  - restaurant tenant
  - Supabase Auth outlet admin
  - profiles row with role=admin and restaurant_id
  - enterprise_outlets link + admin metadata
  - outlet plugin state copied from source restaurant, with p1-enterprise-hq disabled for outlet admin
  - active subscription copied from source restaurant when available
  - operational seed copied from the current source outlet:
    menu items, menu variants, modifier groups, modifiers, item-modifier links,
    floors, tables, kitchen stations, inventory master (quantity starts at 0),
    recipes and recipe ingredients
- Combo configuration IDs are remapped to the new outlet's menu item IDs.
- New outlet login uses the same Anaira application and existing /dashboard, /order, KOT/KDS, billing and inventory flows through restaurant_id isolation.
- Existing restaurants can be connected without copying/deleting their business data.
- Outlet admin credentials are created through Supabase Auth. Password is not stored in plaintext; the UI shows the submitted temporary password once after provisioning.
- Cross-restaurant email reuse is blocked when the existing account is already assigned to another restaurant.
- Enterprise HQ admins can import the current outlet menu into the central catalog.
- Central catalog items can be published to all outlets or selected outlets.
- Publishing preserves source variants/modifier groups when catalog lineage exists.
- Published items become normal restaurant-scoped menu_items, so existing POS/KOT/KDS/billing code is reused rather than creating a second POS implementation.
- Dashboard overview now returns enterprise outlet context and shows outlet code on the restaurant dashboard.

## Security / tenancy
- Outlet admins are not added to enterprise_members; therefore they do not automatically receive Enterprise HQ access.
- p1-enterprise-hq is disabled for newly provisioned outlet admins.
- Enterprise HQ operations remain server-authorized.
- Existing restaurant connection requires ownership (or SuperAdmin).
- Existing business/order data is not copied when using Connect Existing.
- New outlet inventory starts at zero to avoid duplicating physical stock.
