# P1.3 — Advanced Inventory / COGS

Base: P1.2 Payroll build.

Added cost-layer, COGS transaction and recipe-cost snapshot infrastructure. FIFO consumption is protected by row locking and COGS transactions support idempotency keys.

Existing inventory/business data is preserved; this release does not delete or rewrite existing stock.

The connected Supabase project already has the corresponding P1.3 migration applied.
