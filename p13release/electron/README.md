# Anaira Restaurant POS — Standalone Electron Build

This package runs the Next.js application locally inside Electron.
It does NOT load the Vercel/web URL.

Build:
1. npm install
2. npm run electron:build

Installer:
installer/output/Anaira-Restaurant-POS-Setup-1.0.0.exe

Cloud Supabase configuration remains supplied through the production environment.
Do not put Supabase service-role secrets in renderer/browser code.
