# P1.3 Inventory / COGS — Production Completion

Completed on top of P1.2 Payroll ZIP.

## Production hardening
- True FIFO cost-layer consumption using `inventory_cost_layers` ordered by receipt time.
- True weighted-average consumption from remaining cost layers.
- Idempotent cost-layer receipts and COGS consumption.
- Recipe cost snapshots and per-yield cost.
- Food-cost percentage against menu selling price.
- Actual vs theoretical COGS dashboard RPC.
- Waste amount and waste percentage.
- Inventory valuation from remaining cost layers.
- Outlet/restaurant-scoped COGS reporting (restaurant is the tenant/outlet scope).
- Inventory period closing with duplicate-close protection.
- RLS and tenant isolation.
- Inventory Costing & COGS admin workspace.

## Runtime evidence
- FIFO test: 10 units @ ₹100 + 10 units @ ₹120; consume 12 => ₹1,240 COGS.
- Weighted average test on remaining 8 units @ ₹120; consume 4 => ₹480 COGS.
- Period close test: 5 units @ ₹100 => closing valuation ₹500; second close returned duplicate=true.
- Test data was isolated and cleaned after certification.

## Important
Existing business data and existing inventory flows were not deleted or rewritten. Existing Phase 3 functions remain available; P1.3 adds the production costing layer and reporting/closing capabilities.
