# Anaira POS Final Build Kit V23
Use `scripts/build-all-release.ps1` on Windows. It runs npm install, Next production build, Capacitor Android generation/sync, Gradle clean, debug APK build, and Inno Setup compilation when ISCC.exe is installed.

Android build prerequisites on the build PC: JDK 21, Android SDK/platform-tools, npm, Capacitor CLI, and Gradle wrapper generated by Capacitor. End users do not install these separately.

Windows installer prerequisites are provisioned by the existing Inno runtime script; the actual installer is compiled by Inno Setup on the build PC.

Note: do not claim full offline E2E until Airplane Mode testing validates every required screen/API path.
