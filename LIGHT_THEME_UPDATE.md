# Light Theme Update

Added four clean white SaaS themes shared by Restaurant Admin and Super Admin:
- Ivory Graphite
- White Emerald
- Pearl Cobalt
- Paper Coral

They use white/pearl surfaces, graphite typography, restrained borders, and one strong accent color.
Light-mode CSS overrides improve inputs, glass surfaces, badges, sidebar/menu controls, and date inputs.

No database migration is required. Theme presets are code-level definitions and are available through the existing ThemeProvider.
