# Print + KDS final visual fix

- Bill print uses the actual restaurant name/address/phone and GSTIN when enabled.
- Anaira branding is kept only as a small "Powered by Anaira Graphics" footer at the end of the bill.
- KOT print uses the actual restaurant name/address/phone and a small Anaira footer.
- Delivery slip print uses the actual restaurant name/address/phone/logo and a small Anaira footer.
- QR print cards use the actual restaurant name rather than the Anaira brand as the primary restaurant label.
- Kitchen Preparing / Mark Done / Cancel buttons are width-constrained, wrap safely, and remain readable on narrow screens.
