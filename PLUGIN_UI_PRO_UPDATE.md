# Plugin UI Pro Update

Updated:
- `/super-admin/plugins` — advanced app-style Plugin Manager / Control Center
- `/super-admin/plugins/qr-menu` — QR Print Center
- `/super-admin/plugins/whatsapp` — WhatsApp Settings

The UI now follows the restaurant app's theme variables, glass/surface cards, compact stats, responsive grids, search, filters and status controls.

The three master hubs are presented as a dedicated top-level control area:
- Operations Hub
- Restaurant Core
- Restaurant Pro

Also included:
- full plugin catalog migration
- hub catalog entries
- catalog-aware Super Admin plugin API

Run:
supabase db push
npm run build
npm run dev
